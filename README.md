# 台股走勢預測

[![每日訓練](https://github.com/minghan5487/ML/actions/workflows/train.yml/badge.svg)](https://github.com/minghan5487/ML/actions/workflows/train.yml)

預測 0050 成分股未來 20 個交易日的漲跌機率。GitHub Actions 每個交易日收盤後自動下載資料、重新訓練、驗證，最新結果見 **[reports/latest.md](reports/latest.md)**。

## 流程

1. **資料**：yfinance 下載 50 檔個股與加權指數日線（2012 起），FinMind 下載每日本益比、淨值比、殖利率與月營收
2. **特徵**：技術指標，加上依投資專家公開方法論量化的因子
3. **標籤**：未來 20 個交易日報酬 > 0
4. **驗證**：Walk-forward，5 個各 250 日的測試區間，訓練與測試之間間隔 20 日避免標籤重疊造成資訊洩漏
5. **模型選擇**：Logistic Regression、Random Forest、HistGradientBoosting 比較 AUC，新模型不比舊模型差才替換
6. **輸出**：個股上漲機率、各專家觀點、特徵重要性、每次訓練紀錄

## 交易員規則與回測

| 交易員 | 規則 | 回測調整頻率 |
|---|---|---|
| Mark Minervini | 趨勢模板 8 條件：股價在 50/150/200 日線上、均線多頭排列、200 日線上彎、比 52 週低點高 30% 以上、距 52 週高點 25% 內、相對強度 ≥ 70 | 每週 |
| William O'Neil | CAN SLIM：近 3 個月營收年增 > 20%、距新高 15% 內、上漲量 > 下跌量、相對強度 ≥ 80、大盤站上 50/200 日線 | 每週 |
| Jesse Livermore | 突破 20 日高點且成交量 > 1.5 倍均量買進，跌破 10 日低點賣出 | 每日 |
| Steve Burns | 站上 200 日線且 50 日線在 200 日線之上 | 每週 |

回測方式：符合條件的股票等權重持有，隔日才進場（避免用當天收盤資訊當天交易），扣除手續費 0.1425% × 2 與證交稅 0.3%。月營收以公布日（次月 10 日）之後才使用。機器學習策略使用 walk-forward 的樣本外預測，每 20 個交易日持有上漲機率前 10 名。

2013–2026 完整期間：

| 策略 | 年化報酬 | 最大回檔 | 夏普值 |
|---|---|---|---|
| Mark Minervini | +30.3% | -35.0% | 1.39 |
| Steve Burns | +25.1% | -33.1% | 1.44 |
| Jesse Livermore | +12.5% | -34.3% | 0.71 |
| William O'Neil | +9.1% | -51.9% | 0.46 |
| 50 檔平均持有 | +25.3% | -28.3% | 1.50 |
| 加權指數（不含息） | +14.4% | -31.6% | 0.86 |

- 只有 Minervini 在完整期間與近 5 年都贏過 50 檔平均持有，但最大回檔也較深
- 機器學習前 10 名策略近 5 年年化 +20.5%，輸給 50 檔平均持有的 +32.0%；AUC 雖有提升，還不足以轉化成超額報酬
- 股票池是現在的 0050 成分股，有存活者偏差，所有策略報酬都被高估

## 目前結果

以 2021–2026 五個年度測試：

- AUC 約 0.55（隨機為 0.50）：僅技術指標 0.522 → 加專家因子 0.545 → 再加交易員規則 0.553
- 最重要的特徵是大盤距一年高點的回檔幅度、200 日均線乖離、距 52 週高點
- 模型挑出的前 20% 股票，5 個年度中有 4 年的 20 日平均報酬高於全體平均
- 準確率約 57%，但與「全猜上漲」接近，因為這段期間台股多數時間上漲，所以以 AUC 與選股報酬評估較有意義

## 執行

```bash
pip install -r requirements.txt
python -m trend.train
python app.py
```

開啟 http://127.0.0.1:5000 ，輸入股票代碼即可看到明日預測收盤價；`/trend` 是 0050 成分股 20 日走勢儀表板。

## 專案結構

```
trend/config.py     股票清單與參數
trend/data.py       下載股價與估值資料
trend/features.py   特徵工程與專家觀點規則
trend/traders.py    交易員規則（Minervini、CAN SLIM、Livermore、Burns）
trend/backtest.py   策略回測
trend/train.py      Walk-forward 驗證、模型選擇、產生報告
reports/            每次訓練的結果（Actions 自動更新）
.github/workflows/  每日訓練排程
app.py              儀表板與隔日價格預測
```

## 限制

- 成分股清單為手動整理，未隨 0050 調整自動更新，且只包含目前的成分股，有存活者偏差
- 未計入交易成本
- 僅為機器學習練習，不構成投資建議；專家觀點為依其公開方法論量化的規則，並非本人意見
