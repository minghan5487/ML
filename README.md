# 台股走勢預測：一個關於「如何證明自己沒有 edge」的專案

[![每日訓練](https://github.com/minghan5487/ML/actions/workflows/train.yml/badge.svg)](https://github.com/minghan5487/ML/actions/workflows/train.yml)

預測 0050 成分股未來 20 個交易日的走勢。GitHub Actions 每個交易日收盤後自動下載資料、
重新訓練、驗證，最新結果見 **[reports/latest.md](reports/latest.md)**。

**先講結論，因為這是這個專案最重要的部分：**

> **價格方向模型不具備可用於交易的預測能力。**
> 準確率 56.2%，低於「全猜上漲」的 57.0%；最近一折 AUC 0.498，低於隨機。
> 加入交易成本後，策略年化 +21.2% ～ +24.5%，**輸給完全不交易的等權買進持有 +29.9%**。

這個結論不是失敗，是這個專案的產出。股價方向預測本就極難取得穩定 edge；
多數宣稱做到的專案，問題出在驗證設計而不是模型。
本專案的重點在於**用足夠嚴謹的驗證設計，使「沒有 edge」這件事能被可靠地量出來**，
並且每天自動重跑、留下紀錄，讓結論可以被推翻。

同一套管線換一個標籤（波動度而非方向）後，確實得到了正面結果，見 §波動度模型。

---

## 驗證設計

這一節是專案的核心。所有結果的可信度都取決於這裡。

| 機制 | 作法 | 防止什麼 |
|---|---|---|
| Anchored walk-forward | 5 個各 250 交易日的測試區間，訓練集只用測試期之前的資料 | 用未來資料訓練 |
| Embargo | `train_end = test_start − HORIZON`，間隔 20 個交易日 | 20 日標籤與訓練集重疊造成的洩漏 |
| 多數類基準 | 每折並列「全猜多數類」的準確率 | 把「這段期間本來就多頭」誤認為預測能力 |
| 特徵消融 | 每日固定跑 FULL／去除市場層級／僅技術指標三組 | 把對過去市場 regime 的過擬合誤認為學到訊號 |
| 逐折呈現 | 報告列出每一折，不只印平均 | 平均值掩蓋單折崩壞（0.551 的平均藏著 0.498） |
| 點時點對齊 | 月營收以「公布日 + 45 天」而非「所屬月份」對齊 | 看到當時尚未公布的基本面資料 |
| 反證對照組 | 波動度模型與「一行規則」並列 | 把統計常識當成模型的功勞 |

另外兩個刻意的作法：

- **新模型不比舊模型好就不替換**（`REPLACE_TOLERANCE`），避免每日雜訊造成模型抖動。
  代價是：若替換門檻設計不當，模型會靜默凍結而報告看起來正常——
  這個風險在設計審查中被明確指出並處理。
- **無有效折時直接 raise**，而不是讓 `auc.mean()` 回 NaN 後靜默保留舊模型。

## 結果一：價格方向（不可用）

| 指標 | 數值 | 對照 |
|---|---|---|
| 準確率 | 56.2% | 全猜上漲 **57.0%** |
| 平均 AUC | 0.551 | 隨機 0.500 |
| 最近一折 AUC | **0.498** | 低於隨機 |
| 最近一折 前 20% 報酬 | +3.77% | 等權全體 **+5.22%** |

逐折（`reports/folds.csv`）：

| 期間 | AUC | 準確率 | 基準 | 前 20% 報酬 | 全體平均 |
|---|---|---|---|---|---|
| 2021-08 ~ 2022-08 | 0.578 | 53.5% | 50.0% | +2.71% | −0.03% |
| 2022-09 ~ 2023-09 | 0.571 | 58.0% | 59.1% | +4.12% | +2.96% |
| 2023-09 ~ 2024-09 | 0.532 | 57.2% | 57.9% | +1.95% | +1.83% |
| 2024-09 ~ 2025-10 | 0.579 | 56.3% | 55.6% | +5.08% | +1.89% |
| 2025-10 ~ 2026-10 | **0.498** | 56.2% | 62.6% | +3.77% | +5.22% |

**0.551 的平均幾乎全由前四折撐起。** 這正是逐折呈現的意義。

一個容易被當成亮點、其實是警訊的觀察：模型挑出的「上漲機率最高」前 10 名，
近 20 日報酬普遍是 −19% 到 −37%。它學到的是「跌深反彈」，
而最近一折說明這招在當前 regime 不管用。

## 結果二：含交易成本回測（不可用，而且更明確）

| 項目 | 費率 |
|---|---|
| 手續費 | 0.1425% × 2 × 0.5 折 |
| 證券交易稅 | 0.3%（僅賣出） |
| 滑價 | 0.10% × 2 |
| **單次來回** | **0.643%** |
| **年化拖累**（每 20 日再平衡 ≈ 12.6 次） | **8.10%** |

| 組合 | 年化報酬 | 最大回撤 |
|---|---|---|
| 策略（前 10 名，扣成本） | **+21.2% ～ +24.5%**（三次執行的全距，見下） | −16.2% ～ −24.7% |
| 等權全市場（同樣再平衡，扣成本） | +19.99% | −22.1% |
| **等權買進持有（零成本）** | **+29.93%** | −16.8% |

選股有真實的毛超額報酬（對等權全市場 +3.0% ～ +3.6%／年），
但 8.10% 的年化成本把它吃光還倒貼。**扣成本後劣於什麼都不做。**

策略報酬以區間而非單一數字呈現，原因見「一個值得單獨記錄的發現」。

## 結果三：波動度方向（正面結果）

價格方向幾乎不可預測，但波動度有很強的群聚性（volatility clustering）。
標籤改為「未來 20 日實現波動 > 過去 20 日實現波動」，
**其餘完全不動**——同一套特徵、同一套 walk-forward 與 embargo。

| 模型 | AUC | 準確率 | 基準 | 前 10% 把握 |
|---|---|---|---|---|
| logistic | 0.737 | 67.0% | 50.1% | 81.6% |
| random_forest | 0.685 | 62.2% | 50.1% | 80.0% |
| **gradient_boosting** | **0.747** | **68.0%** | 50.1% | **85.0% ～ 85.4%** |

### 對這個數字做的兩個反證測試

85% 看起來太好，所以第一件事是找它為什麼可能是假的。
（三次執行為 85.33% / 85.38% / 84.98%，變動原因見最後一節。）

**測試一：一行規則對照組。** 最無聊的解釋是波動度均值回歸——
過去波動特別低，未來自然放大，不需要機器學習。
對照組：取 `volatility_20` 最低的一成，一律猜「會放大」。

| 資料 | 模型 | 一行規則 |
|---|---|---|
| 合成資料（注入 GARCH 波動群聚） | 85.7% | **87.6%** ← 一行規則勝 |
| **真實資料** | **85.4%** | **76.3%** ← 模型勝，差 9.1 pp，五折全勝 |

（上表取 run 2 的數字；一行規則三次皆為 76.33%。）

合成資料上一行規則獲勝，是因為那組資料裡只有波動群聚，模型沒有別的可學——
這反過來驗證了對照組本身是有效的檢定。

**測試二：有效樣本數。** 波動是全市場同步的。
若「前 10%」集中在少數交易日，筆數再多，有效樣本仍然很少。
實測涵蓋 210～234 個交易日（測試期各 250 日），未發生集中，疑慮排除。

### 這個結果能與不能說明什麼

- 能：波動度的可預測性比價格方向高一個量級，且不只是均值回歸。
- **不能**：它不提供方向。「接下來會比較震」對「漲還是跌」沒有任何資訊，
  不能直接轉成買賣訊號。
- 85% 是**前 10% 把握**時的準確率，全體為 68.0%。
  模型不必每天都有話說，只在它有把握時出聲。
- 波動度的應用（部位調整、風險預算、選擇權）各自需要獨立回測，本專案未做。

## 已知限制

- **存活者偏誤**：成分股為當前名單，所有絕對報酬欄位（含「買進持有 +29.93%」）被系統性高估。
  對「策略 vs 買進持有」的相對比較影響較小。
- **統計檢定力不足**：20 日標籤在相鄰交易日重疊 19/20，每折的獨立觀測僅約 12 個。
  0.551 與 0.5 的差距很可能落在雜訊範圍內。目前未計算信賴區間。
- **上游資料會改寫歷史值**：見下節。
- **回測未計入**：漲跌停無法成交、流動性不足、停牌。
- 僅為機器學習練習，不構成投資建議。

## 一個值得單獨記錄的發現

三次 run 使用相同程式碼、相同筆數的資料，結果如下：

| | 策略年化（扣成本） | 最大回撤 | 等權買進持有 | 等權全市場 |
|---|---|---|---|---|
| run 1 | +24.49% | −16.2% | +29.93% | +19.99% |
| run 2 | +21.24% | −16.5% | +29.93% | +19.99% |
| run 3 | +23.61% | **−24.7%** | +29.93% | +19.99% |

**兩個基準三次完全相同，只有策略在跳。** 報酬差 3.25 個百分點，回撤差 8.5 個百分點。

排查過程：

1. **假設「隨機種子未固定」** → 查 `candidates()`，`random_state=42` 本來就有設。**否定。**
2. **假設「OpenMP 執行緒數不同造成浮點歸約順序差異」** → 以 1／2／4 執行緒實測，
   預測機率至小數 12 位完全相同。**否定。**
3. **檢驗管線本身是否確定性** → 同一份檔案跑兩次，
   特徵矩陣 SHA-256 相同、AUC 至小數 10 位完全一致。**管線是確定性的。**
4. **假設「上游資料改寫歷史值」** → 加入 `上游資料穩定性` 步驟，
   在同一個 job 內相隔數分鐘重新下載並比對 SHA-256。
   結果：**252 個檔案中有 50 個內容改變。** **證實。**

**為什麼這比「數字會跳」嚴重：**

等權基準（+29.93%）與等權全市場（+19.99%）三次完全相同，只有策略在動。
上游的微幅修正在 50 檔平均裡被洗掉了，卻足以讓前 10 名換人——
**代表這個 edge 本來就坐在一堆機率極接近的股票上。**
它不只是估計值有誤差，是選股決策本身對數值上可忽略的擾動不穩健。

在此之前，任何單一超額報酬數字都不該被當作點估計引用；
本 README 的策略報酬因此以區間呈現。

這一節保留完整的排查過程（含三個被否定的假設），
因為前面任何一個若未經檢驗就寫進結論，都會成為長期誤導。
實際上前兩個假設我都一度認為成立，寫進紀錄後才被實驗推翻。

## 執行

```bash
pip install -r requirements.txt

python -m trend.data        # 下載資料
python -m trend.train       # 價格方向模型
python -m trend.vol         # 波動度模型
python -m trend.backtest    # 含成本回測
python -m trend.diagnose    # 唯讀診斷
python app.py               # 儀表板
```

GitHub Actions：`train.yml` 每交易日自動訓練；
`research.yml` 與 `diagnose.yml` 為手動觸發，結果輸出至 Actions 的 Summary。

## 專案結構

```
trend/config.py     股票清單與參數
trend/data.py       下載股價、估值、籌碼、融資券、月營收
trend/features.py   特徵工程、兩種標籤、專家觀點規則
trend/train.py      Walk-forward 驗證、模型選擇、產生報告
trend/vol.py        波動度方向模型與反證對照組
trend/backtest.py   含交易成本回測
trend/diagnose.py   唯讀診斷（不改任何檔案）
reports/            每次訓練與研究的結果
.github/workflows/  每日訓練、研究、診斷
app.py              儀表板
```
